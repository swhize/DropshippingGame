# Dropshipping Simulator – Vom Imbiss zum Imperium

Ein First-Person-Wirtschaftsspiel in Godot 4.7 (GDScript). Du startest als Aushilfe in Kalles Imbiss, kündigst und baust aus deiner Garage heraus eine eigene Dropshipping-Marke auf: Ware einkaufen, einlagern, verpacken, etikettieren, versenden – und über den Laptop "HustleOS" Webshop, Marketing, Personal, Ausbau und Trading steuern.

Alle Modelle, Texturen, Sounds und Musik werden zur Laufzeit prozedural per Code erzeugt.

## Starten
Projekt in Godot 4.7 öffnen und F5 drücken.

## Steuerung
WASD laufen · Maus umsehen · E interagieren · G ablegen · Tab Laptop · Esc Pause · F1 Hilfe
